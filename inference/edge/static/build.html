Roboflow Workflows正在连接设备…应用卡片API
在原生画布中连接设备运行
  1. 复制下方完整运行地址，再打开原生画布。
  2. 点击画布顶部的运行位置（通常为 Locally），在 Running On 弹窗中选择 Other，粘贴完整运行地址并点击 Connect。
  3. 连接成功后，在原生画布中测试工作流，修改后点击 Publish 保存到本设备；持续摄像头或 RTSP 推理请前往“应用卡片”配置、启动并查看结果。

请保留地址中的完整路径，仅填设备 IP 和端口无法运行。此地址包含临时连接凭据，退出或登录满 12 小时后失效；重新登录后请重新复制，勿公开分享。

当前原生本地模式的 Save 草稿按钮不可用，请使用 Publish 保存修改。

连接设备上的 Workflows

使用应用配置中的“访问口令”。进入后使用 Roboflow 原生画布，模型在设备 NPU 上运行。

可在设备应用中心 → Inference → 配置中设置或更改访问口令。

打开原生画布

先复制上方运行地址，打开画布后按步骤设置运行位置。首次连接时，请允许浏览器访问本地网络。

打开原生 Workflow 画布

原生画布需要浏览器联网；本地模式无需 Roboflow 账户。工作流和模型在设备上执行。
